# Parser generation

## Editing the grammar

The parser grammar is maintained in the Peggy grammar source used to generate the parser.
When changing the grammar, edit the grammar definition first and then regenerate the parser output.

For quick grammar experimentation and validation as well as the documentation, use the Peggy online editor:

https://peggyjs.org/online.html

Paste the grammar there, test the rules, and confirm the parse behavior before updating the local source.

## Generated parser file

`ncParser.ts` is autogenerated.
Do not edit it directly, because any manual changes will be overwritten the next time the parser is regenerated.

## Debugging the parser

Use `debugParser.ts` with the `Debug Current TypeScript File` launch configuration.
This will run the `debug()` function in `debugParser.ts`, which contains calls to helper functions that e.g. print the most precise match of a certain type at a given position in the source file, or print the complete AST path at a given position.

The input file for debugging is `fileToDebug.nc`. As it is contained in the `.gitignore`, it can be freely edited for testing different scenarios without worrying about committing changes.
